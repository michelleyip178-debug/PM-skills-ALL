## Description

User Story: As a public officer whose WOG AD authentication fails due to invalid credentials, I want to see a clear error so I know what went wrong and can retry or get help. Acceptance Criteria If my WOG AD credentials are invalid (wrong password, not a recognized public officer account), login fails and I see a clear error message. OTEP renders this error state -- it is not left entirely to WOG AD. Out of scope Account disabled/locked, and network/AD service unavailable -- remain WOG AD's responsibility (see OTEP-71 edge cases). Authorisation failures (no pilot access, no POCDEX profile) -- owned by OTEP-111.
