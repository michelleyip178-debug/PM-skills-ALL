# OTEP-131: Handle missing or broken FormSG application link.

**Type:** Story
**Status:** Backlog
**Assignee:** Unassigned
**Story Points:** 2
**Sprint:** OTEP-Pathfinder Sprint 4

---

## Description

User story: As an officer, I want to see a clear message if the FormSG application link is unavailable, so that I know how to get help rather than facing a broken or missing button.

Acceptance Criteria: If the FormSG link for an opportunity is unavailable or missing, the Apply button is replaced with "Application form unavailable — contact the posting agency". SJR detail pages are out of scope.
