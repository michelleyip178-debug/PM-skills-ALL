# OTEP-1185: [Enhance Search] Search returns esults when querying both Opportunity Title and Agency Name simultaneously

## Description

Description:  When a user enters a search query that contains a combination of an Opportunity Title and an Agency Name (e.g., "Senior data ministry of manpower"), the search fails to return the expected results. According to the development team, this is due to how the current search scoring and thresholds are calculated: The terms "Senior data" match an opportunity title, but the addition of "ministry of manpower" in the string dilutes the overall match score for the title field, pushing it below the required threshold. Conversely, "ministry of manpower" matches an agency label, but the addition of "Senior data" dilutes the score for the agency field, also pushing it below the threshold. As a result, neither field meets the threshold to surface the opportunity, and zero results are recovered. Steps to Reproduce: Navigate to the Jobs and Opportunities search bar. Enter a query that combines a known opportunity title and a known agency (e.g.,  Senior data ministry of manpower ). Execute the search. Actual Result:  No results are returned. The query fails because the combined search terms dilute the match scores across both the title and agency fields below the minimum threshold. Expected Result:  The search engine should be able to parse or score the query effectively enough to return "Senior data" roles specifically tied to the "Ministry of Manpower". Additional Notes / Dev Context: Current State:  The search is accurate and reliable when querying  either  an Opportunity Title OR an Agency individually. It is highly unreliable when attempting a cross-field search. Effort Estimate:  The development team has flagged that adjusting this scoring logic across multiple fields is  not a quick fix . Product/Business will need to prioritize this accordingly.
