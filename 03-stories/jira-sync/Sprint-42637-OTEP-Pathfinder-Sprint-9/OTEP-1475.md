Root Cause Analysis (Opportunity Domain Scope) Investigating  GetOpportunities  in  internal/service/opportunity/ : Sequential DB Round-Trips:  The handler calls  count()  then  find() , causing  two full query round-trips  to PostgreSQL on every request. Correlated Scalar Subqueries:  For every row on the page (15 rows), PostgreSQL executes 3 separate scalar subqueries ( listed_competencies ,  matched_competencies ,  is_ringfenced ), generating  45 subquery executions per request . Missing Targeted Covering Indexes:  Opportunity listing queries with ringfencing exclusion lack covering partial indexes on  posted_date  and  deleted_at . (Note: Officer profile resolution (~30ms) is handled by the upstream team and will remain as-is). 3. Proposed Implementation Changes A. Single-Pass CTE Query with Window Count ( internal/service/opportunity/repository/get_all_query.go ) Merge  count()  and  find()  into a single Common Table Expression (CTE) using  COUNT(*) OVER() : Slice the 15 paginated IDs and total count in one index pass. Batch-aggregate competencies and ringfencing flags  only for the 15 sliced IDs  rather than row-by-row subqueries. WITH paged_ids AS (
    SELECT 
        o.id,
        COUNT(*) OVER() AS total_count
    FROM opportunity o
    WHERE o.deleted_at IS NULL
      AND (o.closing_date IS NULL OR o.closing_date >= (NOW() AT TIME ZONE 'Asia/Singapore')::date)
      AND NOT EXISTS (
          SELECT 1 FROM opportunity_ringfencing rf
          WHERE rf.opportunity_id = o.id
            AND rf.deleted_at IS NULL
            AND ( /* ringfencing filters */ )
      )
    ORDER BY o.posted_date DESC
    LIMIT 15 OFFSET 0
),
competency_aggregates AS (
    SELECT 
        rc.opportunity_id,
        COUNT(*) AS listed_competencies,
        COUNT(*) FILTER (WHERE rc.competency_code = ANY($officer_competencies)) AS matched_competencies
    FROM opportunity_required_competency rc
    WHERE rc.opportunity_id IN (SELECT id FROM paged_ids)
      AND rc.deleted_at IS NULL
    GROUP BY rc.opportunity_id
),
ringfencing_flags AS (
    SELECT DISTINCT rf.opportunity_id
    FROM opportunity_ringfencing rf
    WHERE rf.opportunity_id IN (SELECT id FROM paged_ids)
      AND rf.deleted_at IS NULL
)
SELECT 
    o.*,
    ot.code AS "OpportunityType__code",
    ot.label AS "OpportunityType__label",
    a.code AS "Agency__code",
    a.label AS "Agency__label",
    p.total_count,
    COALESCE(ca.listed_competencies, 0) AS listed_competencies,
    COALESCE(ca.matched_competencies, 0) AS matched_competencies,
    (rf.opportunity_id IS NOT NULL) AS is_ringfenced
FROM paged_ids p
JOIN opportunity o ON o.id = p.id
JOIN ref_opportunity_type ot ON ot.id = o.opportunity_type_id
JOIN ref_agency a ON a.id = o.agency_id
LEFT JOIN competency_aggregates ca ON ca.opportunity_id = o.id
LEFT JOIN ringfencing_flags rf ON rf.opportunity_id = o.id; B.
