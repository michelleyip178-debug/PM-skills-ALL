# OTEP-1487: Exclude hidden role-based competencies (isHidden = true) from Opportunity competency matching logic

**Assignee:** N/A
**Story Points:** N/A
**Sprint:** OTEP-Pathfinder Sprint 9 (42637)

## Description

Description  When a user hides or unhides role-based competencies on the Home page, these changes must immediately reflect in the competency match calculations on both the Opportunity listing cards and the Opportunity details page. Currently, all entries in the  officer_competency  table are included in the match logic. The Opportunity matching service must be updated to filter records based on the  isHidden  flag, ignoring hidden competencies and counting only unhidden ones toward the match score. Acceptance Criteria Hidden Competencies Excluded:  Any record in the  officer_competency  table with  isHidden = true  must be completely ignored during the competency match calculation. Unhidden Competencies Included:  Only records in the  officer_competency  table with  isHidden = false  are counted as valid matches for the user. Opportunity Card Metric:  The "X/Y competencies matched" counter on the Opportunity card must recalculate to reflect only active ( isHidden = false ) competencies. Opportunity Details Rendering:  On the Opportunity details view, required competency tags must only display as matched (checked) if the corresponding record in  officer_competency  is set to  isHidden = false . Dynamic Reflection:  Hiding or unhiding a competency on the Home page must immediately update the match status upon navigating to or refreshing the Opportunities page. Technical Implementation Notes Update the SQL query / ORM filter in the Opportunity matching service to include  WHERE is_hidden = false  when retrieving records from  officer_competency . Combine this logic with the newly added  officer_self_competency  table to ensure complete and accurate competency aggregation before performing the match evaluation.
