## Latest Comments

**Pow Hwee TAN (PSD)** (2026-08-19)
Root cause diagnosis and suggested fix for the duplicated competency match on the Opportunity Detail page: Root Cause Analysis Ingestion / Reference Loader:  In  internal/service/opportunity/importer/importer.go  ( getRequiredCompetencies ) and  ref_resolver.go ,  ListCompetencies  loaded competency records without filtering out inactive/soft-deleted entries, and without deduplicating parsed skill strings from the incoming feed. Database Persistence:  In  internal/service/opportunity/repository/write_repository.go  ( syncCompetencyLinks ), multiple junction rows sharing identical competency names (but mapped to different historical competency IDs/codes) were inserted into  opportunity_required_competency . Controller DTO Mapping:  In  internal/service/opportunity/controller/get_handler.go  ( toOpportunityDTO ), the controller iterates over  o.RequiredCompetencies  without label deduplication, returning duplicate items in the JSON response. Suggested Fix Filter Inactive / Deleted in Importer:  Ensure  ref_repository.go  loads only active, non-deleted competencies ( deleted_at IS NULL AND is_active = true ) and deduplicate incoming required competencies by code/label before persistence. Deduplicate in Detail Controller:  In  get_handler.go , deduplicate  o.RequiredCompetencies  by  CompetencyCode  /  CompetencyName  before assembling the response DTO. Database Cleanup:  Purge duplicate junction rows in  opportunity_required_competency  in the UAT database.
