# OTEP-1404: Fix CI runner disk exhaustion during validate/plan

## Description

As a platform engineer, I want Terraform provider downloads to be shared across stacks in CI so that validate:dev and plan:dev don't fail with "no space left on device." Root cause: terragrunt run --all validate runs 33 stacks, each downloading its own ~600MB AWS provider binary. Total exceeds the linux-medium-amd64 runner disk.  Link:  https://sgts.gitlab-dedicated.com/wog/psd/pdo/intelligence/intelligence-iac/-/jobs/148669550  referencing    merge to main on IaC repo. Fix: Set TF_PLUGIN_CACHE_DIR in the .tg-base before_script so all stacks share a single downloaded provider copy. Acceptance criteria: validate:dev and plan:dev pass without "no space left on device" errors No behavioral change to any stack's plan/apply output The plan is to merge this first, then rebase OTEP-1392 onto main - both MRs should pass.
