# OTEP-1454: MCP backend service missing OpenSearch FGAC reader mapping - 500 on /inference

## Description

Problem : Following the WAF 403 fix (OTEP-1453), the MCP  POST /inference  endpoint now returns an HTTP 500 error. Backend logs reveal an OpenSearch  AuthorizationException  (403,  security_exception ) indicating missing permissions for  [indices:data/read/msearch]  for the role  arn:aws:iam::722448937858:role/mcp-otep-intel-backend-service-task . While the ECS task role has the IAM-layer  es:ESHttpPost  grant on  _msearch , the OpenSearch Fine-Grained Access Control (FGAC) layer does not map this role to the internal  competency_bank_reader  role. The application surfaces this underlying FGAC 403 as an HTTP 500. Root Cause : The OpenSearch migrator's configuration ( 005_role_mapping_competency_bank_reader ) maps standard backend, queue, replay, eval, and judge task roles into the  competency_bank_reader  FGAC role. Because the MCP backend service ( mcp-otep-intel-backend-service ) operates as a separate service on  mcp-cluster , its role was never added to this mapping list. Fix Add an  mcp_backend_role_arn  variable to the migrator Terraform module. Pass this value to the migrator as the  MCP_BACKEND_ROLE_ARN  Lambda environment variable. Append  ${MCP_BACKEND_ROLE_ARN}  to the backend users list in  005_role_mapping_competency_bank_reader.json . Wire the dependency in  live/dev/  to correctly pass the MCP backend service's task role ARN. Ensure the variable defaults to  null  so the token is safely dropped from the mapping in upper environments ( qa ,  preprod ,  prd ) where the MCP backend service does not yet exist. Verification Steps After applying the infrastructure changes in  dev , re-invoke the migrator Lambda manually or wait for the CI pipeline cascade. Ask the AIAP team to re-test the  POST /inference  CV upload and confirm it now returns an HTTP  200  instead of  500 . Check the MCP backend logs to verify the  AuthorizationException  ( security_exception ) is completely resolved. Acceptance Criteria [ ] MCP backend task role is successfully mapped to the  competency_bank_reader  FGAC role in the  dev  OpenSearch cluster. [ ]  POST /inference  returns an HTTP  200  for AIAP CV uploads. [ ] No  security_exception  errors appear in the MCP backend service logs.
