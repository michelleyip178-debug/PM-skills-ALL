## Description

Codify the GCC DNS Route 53 Resolver profile association for the intel-dev VPC ( vpc-066ec2b58890d2034 ) in Terragrunt IaC.\n\n Context:  GCC manages a centralised Route 53 Resolver profile that provides intranet DNS resolution for GCC-connected VPCs. This profile is what allows services inside the intel-dev VPC (and AIAP) to resolve GCC intranet hostnames. The association is not currently in IaC — it needs to be to prevent drift and to replicate to other envs.\n\n What to do: \n1.  Verify current state first:  Check whether the profile is already associated with  vpc-066ec2b58890d2034  in AWS (intel-dev creds required — run  aws route53profiles list-profile-associations ). The creds were expired at time of investigation.\n2. If already associated manually: import the existing association into Terraform state using  terraform import \n3. If not yet associated: create it via  aws_route53profiles_association  resource\n4. Add to the appropriate networking or VPC stack in  intelligence-iac  so it is applied consistently\n5. Replicate to other envs (qa, preprd, prd) once dev is validated\n\n Note:  The GCC DNS profile ARN will need to be sourced from the GCC networking team or central account — it is not provisioned by this ticket.
