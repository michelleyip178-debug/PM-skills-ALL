## Description

Three security and reliability issues in competency-review MCP server identified during pre-VAPT review: JWT signature verification disabled  (src/cognito_jwt.py) - verify_signature: False defeats the purpose of fetching the JWKS signing key. Attacker could forge tokens. Caller identity not propagated  (src/main.py) - id_pocdex hardcoded to "unknown". CIE backend cannot audit which officer triggered inference or enforce agency-level data governance. Fix: decode gw-inbound-auth-token header as per Govtech Harness Docs. and pass Cognito sub as caller identity. No HTTP/S3 client reuse  (src/main.py) - New httpx.AsyncClient and boto3.client("s3") created per tool call. Wastes TCP+TLS handshakes, risks socket exhaustion under load. Fix: shared clients via Starlette lifespan. Edits:  Custom lifespan broke FastMCP tool discovery (gateway 500) httpx/boto3 clients safe to create at module level
