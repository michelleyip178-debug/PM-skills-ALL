## Description

Create a public Route 53 hosted zone for  dev.hrhub.gov.sg  in the intel-dev account (722448937858) via Terragrunt IaC in intelligence-iac.\n\n Purpose:  ACM DNS validation only. End-user DNS resolution is handled by GCC DNS — this zone exists solely so ACM can place and verify its CNAME challenge records automatically, enabling hands-free cert renewal.\n\n What to do: \n1. Add a new Terragrunt stack (e.g.  live/dev/dns/public-zone/terragrunt.hcl ) that creates  aws_route53_zone  for  dev.hrhub.gov.sg  (public, not private)\n2. Output the zone ID so the ACM cert stack can reference it for automatic CNAME creation\n3. After apply, extract the NS records and  raise a delegation request  to the owner of  hrhub.gov.sg  (MCI / GovTech domain team) to delegate  dev.hrhub.gov.sg  to the Route 53 name servers — without delegation, ACM validation will time out (this is the same root cause that caused the 3x VALIDATION_TIMED_OUT failures on  cie-inference.dev.intelligence.gov.sg )\n\n Note:  No A/CNAME records for  cie-intelligence.dev.hrhub.gov.sg  are needed here — GCC DNS handles resolution for intranet clients.\n\n Blocked by:  NS delegation from hrhub.gov.sg domain owner.\n Blocks:  ACM cert ticket.
