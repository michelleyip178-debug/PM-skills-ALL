## Description

User Story As a logged in officer, I want to be able to report the issue of not being able to view my role-based competencies so that someone can fix it for me.  Acceptance Criteria Report issue button is red in its active state and clickable by a logged in officer  Once clicked, a notification toast will appear to confirm that we have received the alert and will work on the issue The Report issue button will turn to grey and remain in inactive state until the issue is fixed by us
