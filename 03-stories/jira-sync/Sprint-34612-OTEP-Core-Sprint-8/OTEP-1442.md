## Description

The competency ingest flow starts background processing after the HTTP request returns. Today, the async ingest path loses request-scoped log correlation, so downstream logs do not consistently include  request_id  and  trace_id . Problem  In  download_load_competency_service.go , the ingest goroutine runs independently from the request lifecycle. Without explicitly copying correlation metadata into the background context, logs emitted during XML/Excel/CSV processing cannot be reliably tied back to the originating request/trace. This makes it harder to: trace ingest failures end-to-end correlate async loader errors with the original API request debug background processing in centralized logs/observability tools Scope Preserve async log correlation for competency ingest: request_id OpenTelemetry  trace_id Include and validate course import checks for: required  CourseTypeAbbreviation required  WebLink valid URL format HTTPS-only URL requirement Do  not  carry over other request-scoped context values. Proposed Change  In  download_load_competency_service.go : replace the background ingest context setup with a detached context helper build the background context from  context.Background() copy only: request ID from  requestctx OpenTelemetry span context for trace correlation Add/keep unit coverage in  download_load_competency_service_test.go  to verify: request_id  is preserved trace_id  is preserved parent request cancellation does not stop background ingest Acceptance Criteria Background ingest logs include the original  request_id  when one exists. Background ingest logs include the original  trace_id  when one exists. The async ingest goroutine is not cancelled when the originating HTTP request ends. No other request-scoped values are propagated into the detached background context. Targeted unit test coverage exists for the detached context behavior. Impact / Risk Low risk, localized to async ingest logging context. Improves observability without changing ingest business logic. Avoids broader context leakage by copying only correlation metadata. Validation Run targeted competency domain tests covering detached ingest context behavior.
