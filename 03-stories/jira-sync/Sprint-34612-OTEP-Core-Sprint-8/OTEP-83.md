## Description

User Story As an officer, I want to browse and search across the full course catalogue so that I can discover and apply for courses relevant to my learning needs.  Acceptance Criteria Refer to the attached “DLE Common Services PRD” document attached to match the data fields that we take from CSC Search & Discover Page Entry points Clicking  "Explore more courses"  from the Courses landing page navigates the officer to the Course Search & Discover page. Running a search on the Course landing page will also redirect to the search results on this page.  The page contains: Search bar Filter panel Search results Results count (only when search is ran) Pagination controls  Search Bar The search bar displays the placeholder text  "Search courses"  when empty. Officers can search by: Course Name - field “Course_type_Description” Domain - field “DomainName” Programme Code - “Course_type_Abbreviation” Search is executed when the officer: Clicks the  Search  button. Presses  Enter . Selects an autocomplete suggestion [ update as if 18 Aug.]  If the user wants to search for a new search term, they need to backspace and type the new keyword and hit Enter or “Search” to run the search again. If the user backspaces to a blank search bar and hits enter or click Search, it will bring them back to default search and discovery page If the user backspaces to a blank search bar and does not hit enter or click Search, nothing will happen  Autocomplete Autocomplete is triggered only after the officer has entered at least  3 characters . A maximum of 8 autocomplete suggestions is displayed. Autocomplete suggestions are grouped into the following categories Domains Course Names Within each category, autocomplete suggestions are ranked in the following order: Starts with the search term. Contains the search term. Suggestions within each ranking group are sorted alphabetically. When the search field is cleared, all autocomplete suggestions are removed.  Search Results Selecting a Domain autocomplete suggestion automatically applies the corresponding Domain filter When a Domain autocomplete suggestion is selected, matching courses are ranked in the following order (across all courses, not just courses tagged with that domain): Courses that is tagged to the domain, whose title contains the domain name Courses that is tagged to the domain, whose content contains the domain name All other courses that are tagged to the domain whose domain name does not appear in title or content Courses that is not tagged to the domain, whose title contains the domain name Courses that is not tagged to the domain, whose content contains the domain name Selecting a Course Name autocomplete suggestion returns the selected course in the search result page. When the officer performs a free-text search without selecting an autocomplete suggestion, the search is performed across the entire course catalogue. Free-text search results are ranked in the following order: Course title contains the full search phrase Course title contains all search words (in no particular order) Course title contains individual search words Course content contains the full search phrase Course content contains all search words (in no particular order) Course content contains individual search words Courses in search results are displayed using the standard Course Card design as in this ticket     The total number of matching courses is displayed above the search results and updates dynamically whenever the search query or filters change. Clicking a Course Card opens the Course Details page in a new browser tab. Filters Officers can filter courses by (the content of the filters are under section Filter Values) Class Type Domain Provided By All filters are unselected when the page first loads. Officers can select multiple values within the same filter category. Officers can select values across multiple filter categories. Available filters should be updated dynamically according to search results and filters, so that the officer will not end up clicking on a filter that does nothing (eg. if i search for data, and 100 results are returned, and all 100 are e-learning, then “classroom” filter should not be shown) Search results update dynamically whenever filters are selected or deselected. (regardless whether there is an active search or not) A  Clear  action is displayed at the top of the filter panel. Clicking  Clear  removes all selected filters while retaining the current search query. Clearing both the search query and all filters returns the page to the default state. Filters with no associated courses are not displayed in the filter.  Domain Filter The filter is labelled  Domain . The filter displays the complete list of business-approved Domains - see the bottom of the page for the entire list of 44 domains (here: OTEP Agency Family List.xlsx )  Filter Values Class Type values are: Classroom Digital Learning Digital Resources Events  Milestones Provided By values are: Civil Service College Harvard Business Publishing LinkedIn Learning Udemy Domain values - > Competencies Functional Area tab > FROM LEARN  OTEP Agency Family List.xlsx  Pagination Search results display 15 courses per page. Pagination controls are displayed only when more than 15 courses are returned. On the first page, the  Previous  pagination control is hidden or disabled. On the last page, the  Next  pagination control is hidden or disabled. Navigating between pages retains the current search query and applied filters.  Jumpstart Recommendations Swimlane There is a swimlane at the bottom of the course pagination showing the jumpstart recommendations The swimlane shows 3 courses at a time, showing a maximum of 25, behaving the same way as the swimlane on the landing page      Filter Panel The filter panel scrolls independently from the search results.  Empty State If no courses match the search criteria, an empty state is displayed. The empty state displays the following copy: Header:   No matching courses found Subheader:   Try using different keywords or adjusting your filters to explore more learning opportunities. Officers can modify their search query or filters directly from the empty state without leaving the page.  Default Page State When no search query or filters have been applied, all available courses are displayed. The total number of available courses is displayed above the search results. By default, courses are sorted in the following order: Earliest upcoming start date  Alphabetically by Course Name.
