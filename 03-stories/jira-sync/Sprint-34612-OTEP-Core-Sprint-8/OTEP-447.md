## Description

User Story As a logged-in officer, I want to view recommended target roles based on my current role, grade, and competency profile, so that I can compare relevant career options and understand the competency gaps I need to close. Acceptance Criteria General The section is titled “Based on your current role” and includes a subheader below. Subheader “Discover roles tailored to your experience level and career path.” Recommended Role List (Left panel) Officers will only see recommended roles here IF the officer has a role and grade If there is no role and grade, then this section will default to the empty state (   ) There should be a link to “Explore new roles” page The officer sees a maximum of 5 recommended roles in the left panel. Each recommended role card displays the role title, competency match percentage, and a visual progress bar. Progress bar colours are based on match percentage: 0–29%: Grey 30–69%: Orange 70% and above: Green Recommended roles are ranked by competency match percentage, from highest to lowest. The recommended roles list contains exactly 3 lateral roles and 2 vertical roles (role logic in next section) By default, the page will load with the 5 roles  The first role on the list highlighted and detail panel showing the comparison until the user clicks another role.  Only one role can be active at any point of time When the officer selects another role,  the selected role becomes active  the previous role becomes inactive  the right-side detail panel updates. Recommended role logic  - from role profile The 5 recommended roles in the list are made up of: 2 vertical roles - 1 grade above 3 lateral roles - same grade Vertical role logic Must be: Within the officer’s agency Within the same Job Family AND Job Function If fewer than 2 roles: Expand to same Job Family within same agency If there are still fewer than 2 roles Expand to any role within the same agency If more than 2 roles: System selects any 2 roles by random Lateral role logic  Must be: Across agencies, exclude officer’s agency Within the same Job Family AND Job Function If fewer than 3 roles:  Expand to same Job Family across other agencies  If there are still fewer than 3 roles Expand to any role across other agencies If more than 3 roles: System selects any 3 roles by random Recommended role logic - based on officer’s role profile  The system must preserve the 2 vertical and 3 lateral role split throughout all fallback logic.  If the officer's current role is missing a Job Function: Search using Job Family only. If insufficient roles are found, expand to Agency. If more than the required number of roles are returned, randomise and select the required number If the officer's current role is missing both Job Function and Job Family: Search using Agency only. If more than the required number of roles are returned, randomise and select the required number. If the officer's current role has one Job Family and multiple Job Functions, search in the following order: Job Family 1 + Job Function 1 Job Family 1 + Job Function 2 Consolidate all eligible roles returned before randomisation. If the officer's current role has multiple Job Families and multiple Job Functions: Search all Job Family / Job Function combinations in sequence. Example order: Job Family 1 + Job Function 1 Job Family 1 + Job Function 2 Job Family 2 + Job Function 1 Job Family 2 + Job Function 2 Continue for all remaining combinations. Consolidate all eligible roles returned before randomisation. Recommended roles - General Where duplicate roles are returned across multiple search combinations, duplicate roles must be removed before randomisation, ranking and display. After vertical and lateral roles have been selected, the final list must be sorted by competency match percentage across all 5 roles. Where two or more roles have the same competency match percentage, lateral roles must be ranked ahead of vertical roles. Roles with no Job Family, Job Function or competencies will never be recommended. These roles will never be recommended:  no grade no competencies roles with grades JR 7, 6, 5, 4, 3, 2, 1 (sensitive information) Competency Matching and % logic  Compare the functional competencies tagged to the role based on the role profile sheet -  Role Profiles Bank for OTEP MVP.xlsx  against the functional and self-declared competencies from the user’s profile Core competencies are excluded from competency matching at all times.  To get the % match, overlapping competencies divided by total functional competencies required for the selected role x100 the display value should be rounded to the nearest whole number  Exclude any roles with 0% competency match   Roles that do not have a Job Family or Job Function must be excluded before competency matching and recommendation logic is applied Role Detail Panel (on the right) The panel displays  role’s title agency job family the number of competencies matched  the number of competencies missing  The matched competency count must equal the number of competencies tagged “You have this.” The missing competency count must equal the number of competencies tagged “To develop.” Display all the functional competencies associated with this role, from the Role Profiles Bank, as a list  The competency description is always collapsed by default Each competency row displays: Competency name Match status Expand/collapse accordian Each competency has one of the following statuses: “You have this” — the competency overlaps with the officer’s profile competencies “To develop” — the competency does not overlap with the officer’s profile competencies Each competency row is an accordion and can expand or collapse When a competency accordion is collapsed, the row displays: Competency name Match status Expand icon When a competency accordion is expanded, the row displays: Competency name Match status Competency description Competency descriptions are sourced from competency bank If no competency description exists, display the same no description found message as per profile page instead A “+ Expand all” control is displayed above the competency list. When the officer clicks “+ Expand all”: All competency accordions expand The control changes to “- Hide all” When the officer clicks “- Hide all”: All competency accordions collapse The control changes back to “+ Expand all” The detail panel remains visible and populated when the officer switches between recommended roles. Wherever there is a loading time, please replace with the loading component until the content loads
