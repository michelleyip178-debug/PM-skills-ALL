## Description

Branch builds clobber  :latest  for all three images on every push; cie-ingest task defs pin mutable  :latest  (promotion MRs produce no diff → the deploy  changes:  rule never fires, and there is no audit of which digest runs); migrate-evalstore depends on  :latest  ordering ( needs: publish-inference ). Tasks cie-backend: tag  :latest  only on main (rules on  .kaniko-build  / conditional second  --destination ) config-repo: sha-pin cie-ingest task defs; include ingest in the promotion flow (hand-authored MRs OK, but tags must be immutable so the diff/audit works) [IaC]  iac handoff: eval-store-migrator task def takes image via  containerOverrides  at RunTask; migrate-evalstore passes  $ECR_REPO_INFERENCE:$CI_COMMIT_SHORT_SHA  — removes the  :latest  race Evaluate digest pinning ( image@sha256:  in promotion MRs, resolved at MR-open via  skopeo inspect ) + cosign keyless signing via the existing OIDC token Fix the  .containerDefinitions[0]  assumption: select container by name in the deploy jq,  run_gate_task.py , and  open-promotion-mr.sh Acceptance criteria:  No branch push mutates  :latest ; every deployed image traceable to an immutable tag/digest.
