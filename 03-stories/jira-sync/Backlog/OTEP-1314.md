## Description

Related UAT / Defect Tickets OTEP-1235: [PANEL] PANEL-01 - Role panel shows the correct agency and function (OTEP-694) OTEP-1307: UAT - Exclude WOG role profiles OTEP-1234: [NAME] NAME-01 - Role names show without the grade suffix everywhere they appear (OTEP-669) Background & Problem Statement The backend maintains an asymmetric split role model across two separate database tables: 'job' (agency-scoped roles with agency_id and cleaned titles) and 'role_competency' (WOG master profiles with NULL agency and uncleaned titles). This polymorphic duality causes recurring system defects: OTEP-1235 / OTEP-1307: WOG roles have NULL agency_id, causing blank agency labels on UI role cards and breaking agency filtering, leading to a temporary workaround that excludes WOG roles entirely from recommendations. OTEP-1234: process_job.go cleans grade codes via CleanJobProfileName(), but process_wog_role.go ingests raw titles without cleaning, causing grade codes/numbers to persist in WOG roles. Query fragmentation: Repository queries (Search, Recommendations, Detail) constantly construct ad-hoc UNION ALL queries with hardcoded 'job' vs 'role_competency' source branching. Proposed Technical Solution Decouple the master Job Profile (ref_job_profile) from agency-specific contextual usage (agency_job_profile) into a clean relational schema. Apply CleanJobProfileName() universally across all ingestion pipelines. Eliminate polymorphic UNION ALL branching in repository queries by querying a unified role entity. Restore cross-agency WOG talent mobility recommendations without blank agency metadata issues.
