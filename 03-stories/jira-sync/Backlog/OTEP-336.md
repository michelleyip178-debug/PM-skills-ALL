# OTEP-336: View matched competencies on opportunity detail page

**Type:** Story
**Status:** Backlog
**Assignee:** N/A
**Story Points:** N/A

---

## Description

User story:  As an officer, I want to see which of this opportunity's required competencies I already have when I view the detail page, so that I can assess my fit before deciding to apply.  Acceptance Criteria For Internal Jobs: The detail page renders a "Competencies" section listing each required competency for the opportunity. Each competency shows one of two states — matched or unmatched — based on whether it appears in the officer's POCDEX competency profile. No proficiency level is compared. If the officer's competency profile fails to load, the section renders the opportunity's competency list without match states. No error is surfaced to the officer. For Gigs and STIPs: The detail page renders the opportunity's competency tags under the heading "What you'll develop." The officer's profile is not referenced. General: If the opportunity has no competency data, the competency section is not rendered. It does not appear as "Not specified." Competency data on this page is read-only. The officer cannot edit their profile from the detail page.
