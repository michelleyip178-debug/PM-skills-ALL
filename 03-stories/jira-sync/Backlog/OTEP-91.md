# OTEP-91: Search opportunities by keyword

**Type:** Story
**Status:** Backlog
**Assignee:** N/A
**Story Points:** N/A

---

## Description

User Story As an officer, I want to search across all opportunity listings using free-text keywords, so that I can surface postings relevant to my interests without browsing the entire list. Acceptance Criteria A keyword search field is visible and accessible on the hub listing page Search queries across opportunity title, description, and agency fields at minimum Results update on submit (not required to be real-time / typeahead for MVP) Zero-results state displays clearly with prompt to broaden search or clear filters Search works in combination with filters (type, C@G indicator) Search is elastic — partial matches and minor typos return relevant results
