## Description

User Story As an officer, I want to view the gap analysis between my current and saved target roles, so that I can easily see my areas of development.  Acceptance Criteria Displays Role title Users can see a summary of the number of competencies matched vs missing CTA showing “Save as target role” Clicking this will save this as a target role under the Target role container (ticket    )  There is an indication of “My target role” in the panel so the user know the save has been successful  the old CTA for “Save as target role” will change to become “Remove as target role”. After the role is saved in the Target role container above the page it is selected as “active” in container >  to confirm with Liting - does that mean that both sections will show the same role, with the same comptencies listed?  Display all the functional competencies associated with this role, from the Role Profiles Bank, as a list  Each competency name should be stated clearly Users can see an indication of whether a particular competency overlaps with one on their profile  “You have this” - overlaps with a competency on their profile “To develop” - does not overlap with a competency on their profile  Each competency is an accordian where they can expand to show the competency description  “+Expand all” toggle is available, upon clicking, it expands all the competencies descriptions and changes to “-Collapse all” “-Collapse all” collapses all the accordians so you only see the competency names and not the descriptions
