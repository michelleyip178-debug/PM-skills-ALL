## Description

User Story As an officer, I want to report an issue from the Career Compass footer so that I can provide feedback on problems I encounter while using the product. Background The footer currently contains a  Feedback  link which directs officers to a FormSG form that includes both satisfaction rating and issue reporting. A separate satisfaction rating component is being introduced across Career Compass under  OTEP-1212  to capture CSAT. To avoid duplicating the satisfaction rating capability, the existing footer  Feedback  link should be repurposed specifically for issue reporting once the new satisfaction rating component is available. Dependency / Pre-requisite This ticket is  blocked by OTEP-1212 . The footer change  must only be implemented/released after the satisfaction rating component in OTEP-1212 has been completed and is available to officers . Until OTEP-1212 is live, the existing  Feedback  footer link and behaviour should remain unchanged so that officers continue to have access to the existing satisfaction rating capability. Jira dependency: OTEP-1212 blocks this ticket. Acceptance Criteria Once the satisfaction rating component in  OTEP-1212  is available, replace the existing footer link label  “Feedback”  with  “Report Issue” . The  “Report Issue”  link should remain in the same position in the footer as the existing Feedback link. Clicking  “Report Issue”  should direct officers to the existing FormSG link:    The footer change must not be released before the satisfaction rating component in  OTEP-1212  is available. Until OTEP-1212 is available, the existing  “Feedback”  label and behaviour should remain unchanged. Once this change is released, satisfaction ratings should be captured through the separate Career Compass satisfaction rating component rather than through the footer. No other footer links or footer behaviour should be changed as part of this ticket. The footer should contain the following links after the change: Privacy Statement Terms of Use Report Vulnerability Report Issue
