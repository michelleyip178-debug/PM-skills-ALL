# OTEP-988: Frequency of updating officer details on POCDEX

**Type:** Story
**Status:** Backlog
**Assignee:** N/A
**Story Points:** N/A

## Description

Currently, pocdex details are only pulled ONCE, upon login. However, that means that whenan officer’s details are updated, eg missing information is populated, or jobid is updated, Compass does not display the latest details Updates are made on HR side without our kbowledge - eg changes to competencies tied to job ID, job ID updated  Updates are made prompted by BOs due to an error such as missing fields  Profile reloads entirely, including competencies when we update the data - what happens to old competencies? move competencies into a new “old” role-based competencies. Should we allow for the updating of selected fields eg name, agency on Compass only but not synced to pocdex? Then there are different sources of informational truth
