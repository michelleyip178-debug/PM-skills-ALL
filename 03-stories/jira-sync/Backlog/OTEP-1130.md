## Description

The Keycloak sign-in page rendered the stock KEYCLOAK logo instead of Career Compass. On Keycloak 26 the default keycloak.v2 login theme hides the display-name span and draws its own logo via div.kc-logo-text background-image, so the realm displayNameHtml alone cannot change the branding. A custom login theme with loginTheme set on the realm is required, and locally the theme must also be mounted into the container. Changes otep-keycloak: new career-compass login theme (inherits keycloak.v2, overrides logo with Career Compass SVG); loginTheme set on dev/qa realms; baked into images via existing COPY themes/ in Dockerfile. otep-service: mount the theme into the local docker-compose Keycloak container and set loginTheme in the imported realm-export. Merge Requests otep-keycloak!5  — the login theme + loginTheme on dev/qa realms otep-service!255  — local docker-compose theme mount + loginTheme in realm-export Notes uat/prd realm configs are still placeholders (OTEP-759). Add loginTheme when those realms are onboarded.
