# OTEP-984: Profile card - First /Last name missing

**Type:** Story
**Status:** Backlog
**Assignee:** N/A
**Story Points:** N/A

---

## Description

User Story As a logged-in officer whose first name or last name may be unavailable (or both), I want my available name information to be displayed correctly so that I can still identify my profile without seeing blank or incorrect information. Acceptance Criteria — Missing First Name or Last Name If  firstname  is available and  lastname  is blank or unavailable, display only the first name. If  lastname  is available and  firstname  is blank or unavailable, display only the last name. If  firstname  is blank or unavailable, use the first letter of the last name for the avatar icon. If both  firstname  and  lastname  are blank or unavailable: a. Hide the name field.  b. Display the default profile avatar without initials. Missing name fields must not result in additional spaces or display values such as  null ,  undefined , or  NA .
