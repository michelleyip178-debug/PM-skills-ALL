## Description

User story As a logged in officer, I can add, view, switch between and remove target roles, so that I can track multiple career goals and understand my readiness for each role.  Acceptance Criteria General Elements Users can see a “Target Roles” section on the page  Users can see two CTA buttons to “add target role” and “Explore new roles” Users can save up to 3 target roles and clear instruction is shown to the user of this limitation - “Choose up to 3 targe roles you’d like to work towards.” Empty State In the empty state where the user has not saved any target roles, there is a message explaining “You haven’t set any target roles yet” with supporting text The supporting text will also contain two links to “based on your current role” and “explore new roles”  Clicking “Add target role” will open up a modal - See ticket -     “Clicking “Explore new roles” will bring you to the “Explore new roles” page. See ticket -     Clicking on “based on your current role” will shift the viewport down to “Based on your current role” - See ticket     Target Role Pills and selection behavior Saved target roles are displayed as selectable pills at the top of the container Each chip displays the role title Only one target role can be active at a time The active role is visually highlighted and will populate the detail panel below - See Ticket     Clicking on another chip will switch the active role and also updates the detail panel accordingly Officers can save up to a maximum of 3 target roles  If the limit is reached, the button remains enabled Clicking it triggers a modal overlap that lets the user remove a saved target role  Removing a target role Users will see a message expressing that the maximum limit of 3 has been reached Users will see a selectable list of currently saved target roles Each role is displayed with a checkbox and the role title  When the user clicks a checkbox, the entire selection is highlighted  One or more roles can be removed in this modal the “Next” button is disabled by default the “Next” button is only enabled when at least one role is selected Clicking “cancel” will close the modal and no changes are saved  Clicking “Next” takes the user to the “Add Target Role” modal
