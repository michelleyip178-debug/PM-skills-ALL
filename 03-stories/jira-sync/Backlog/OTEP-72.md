## Description

User Story As a new officer joining public service, I need to be able to login to OTEP smoothly after onboarding and see my role competencies. Acceptance criteria OTEP account is created for the new officer with their profile information User will log in using Singpass When they login, they should see the default view of viewing his profile details and My Competency section. Tech When a new officer onboards, their profile will be created by the respective agency HR in either HRPS or Cumulus This record will get pushed into POCDEX and into OTEP (instantaneously) Account is created on OTEP Questions is there any lag time? Rama: no, it is instantaneous updates
