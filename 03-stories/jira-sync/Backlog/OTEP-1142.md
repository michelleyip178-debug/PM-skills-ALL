## Description

No coverage measurement exists (bare  pytest -q ); no SonarQube anywhere in the CIE repos. SHIP-HATS provides a central SonarQube; the ship-hats-templates scan job auto-enables when  SONAR_TOKEN  is set (credential-gated pattern). Tasks Raise SHIP-HATS service request: onboard cie-backend to the central SonarQube Provision  SONAR_TOKEN  +  SONAR_PROJECTKEY  as masked+protected project variables on cie-backend Add  pytest-cov  to  [dev]  extras; change unit-tests to  pytest -q --cov=cie --cov-report=xml --cov-report=term Add  coverage:  regex + cobertura  coverage_report  artifact (MR coverage-diff widget) Add sonar-scanner job (test stage,  GIT_DEPTH: "0" ), feed  coverage.xml  via  sonar.python.coverage.reportPaths Decide and set a coverage floor (reference system uses  --fail-under=80 ; measure the realistic baseline first) Do NOT set  QUALITY_GATE_WAIT=false  (the SHIP-HATS bypass knob)  Acceptance criteria:  SonarQube dashboard shows the project with coverage; MR widget shows coverage delta; quality gate reflected in the pipeline.
