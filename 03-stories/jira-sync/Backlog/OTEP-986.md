# OTEP-986: Ringfencing should apply to officer with multiple employments

**Type:** Story
**Status:** Backlog
**Assignee:** Thomas Huchedé
**Story Points:** N/A

---

## Description

One officer could have multiple employments.  For the opportunity ringfencing, we only apply the criteria on the first employment so far and will need to extend the matching to all current employments. Acceptance criteria Officer with a second employment whose Agency is excluded from an opportunity should not be able to access the opportunity detail page Officer with a second employment whose Job family is excluded from an opportunity should not be able to access the opportunity detail page Officer with a second employment whose Job function is excluded from an opportunity should not be able to access the opportunity detail page
