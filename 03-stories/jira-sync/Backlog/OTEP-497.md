## Description

Description:  UI feedback was received that the typography and layout spacing on the Opportunities detail page are currently inconsistent. The section titles do not match in size, and the line spacing between the two text blocks needs to be uniform. Acceptance Criteria:  Standardise heading:  Ensure the primary title in the top layer (e.g., "[Gig] Social Media Content...") and the section title in the bottom layer(e.g., "About this opportunity") use the exact same font size, weight, and styling. Standardise secondary headings:  The secondary information in the top card (e.g.,  the blue info box text, and the "Posted on" date) must use the designated smaller text style, ensuring a clear visual hierarchy compared to the body text. Body Text Uniformity:  All standard paragraph text in the bottom card (under "About this opportunity") must be updated to use the unified primary body text style, ensuring it is visually consistent with the main body text in the top card. Uniform Line Spacing:  Standardise the line height and vertical margins between text blocks, specifically addressing the inconsistent line breaks in the "About this opportunity" body text.
