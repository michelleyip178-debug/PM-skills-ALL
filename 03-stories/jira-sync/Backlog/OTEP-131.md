# OTEP-131: Handle missing or broken FormSG application link.

**Type:** Story
**Status:** Backlog
**Assignee:** N/A
**Story Points:** N/A

---

## Description

User Story As an officer, I want to see a clear message if the FormSG application link is unavailable, so that I know how to get help rather than facing a broken or missing button. Acceptance Criteria Current - If the FormSG link for an opportunity is unavailable, it will show when I land on the form itself.  If the FormSG link can be detected removed or unavailable, then the CTA will be disabled and in the details page, to show “Application form unavailable - contact [Agency POC] directly”
