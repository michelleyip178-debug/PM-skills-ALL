# OTEP-1167: Logout button is unresponsive after session timeout

**Status:** To Do
**Assignee:** N/A
**Story Points:** N/A
**Sprint:** OTEP-Pathfinder Sprint 8 (34622)

---

## Description

Issue  When a logged-in user leaves the application tab open until their session expires, clicking the "Logout" button from the nav bar results in no UI response. The user is not redirected and remains trapped on the current page (Silent Failure / 404 on background fetch)   Expected Result Clicking the "Logout" button after a session expires should gracefully handle the invalid session state like other tabs. The application should clear any stale local user data and  perform a hard redirect to the Login screen.
