# OTEP-77: Officer who changes role

**Type:** Story
**Status:** Backlog
**Assignee:** N/A
**Story Points:** N/A

---

## Description

*User Story*

As an officer who just changed to a new role or got a promotion, I will still see my old role competencies on my profile, so that the system knows the lifetime competencies that I have

*Acceptance criteria*

*Profile Card*

# Officer’s details will be updated
## first name - update if there is a change
## last name - update if there is a change
## {{employment title/business title}}
## Agency - update if there is a change
## Email - update if there is a change

*Competencies*

# The officer will see their competency profile automatically updated upon logging in and landing on this page
# Officers will see their role-based competencies updated with the new role’s competencies 
# Officers will see his outdated role-based competencies get shifted to the self-declared competency section 
## Compare the new role’s competencies against the user’s current competencies (all role-based and self-declared). Any new competencies will be added under the role-based functional competency section, categorised and displayed under the core or functional competencies respectively, by type.
## If the new role competencies overlaps with the old role competencies, keep them in the role-based competency section
## The old role’s outdated competencies which are not found in the current role will be moved to “Additional Competencies”.
# No competencies should be duplicated

----

*Tech Notes*

* Profile changes will only be made if there is a new role update from the HR systems. ie. officers on a short-term GIG or temporary job posting will not have their profile updated with new competencies
