## Description

Implement the user profile page UI to display user information and integrate with the backend API to fetch and render the data.

⸻

Scope

* Create UI to display:

* First Name

* Last Name

* Employment Title

* Agency

* Integrate with API:

* GET /users/{userId}

* Bind API response to UI components

⸻

Acceptance Criteria

* Profile page UI is implemented according to design

* API is successfully called and data is displayed correctly

* Loading state is shown while fetching data

* Error state is handled (e.g. API failure)

* Handles empty or missing values gracefully

* Page is accessible only after successful authentication

* UI is responsive and aligned with design standards

⸻

Notes

* Ensure proper handling of null/undefined values

* Follow existing UI/UX guidelines

* Coordinate with BE for API contract
