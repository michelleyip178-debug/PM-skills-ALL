## Description

User Story As an officer, I want to see a clear navigation bar so that I can clearly navigate across all the key pages of the website  Acceptance criteria OTEP logo (WIP) “Home” - clicks to Officer profile page “Jobs and opportunities” - clicks to Jobs landing page “Learning and courses” - clicks to courses landing page  “Your development” - clicks to my development landing page  Avatar Letter will be the first name of the officer - cannot be changed by the officer Clicking on the avatar will bring a drop-down with a single option to “Log Out” Clicking outside the dropdown closes the dropdown “Logout” will trigger:    Ends the authenticated session User redirected to login. User should clearly distinguish between active and inactive state  Active state updates when the user navigates between pages Clicking a navigation item routes the user to the corresponding page  navigation occurs without requiring a full browser refresh If user is already on a particular page, clicking it again will do nothing eg. if i am already on Home, clicking Home again will remain on current page  No page refresh Clicking on the logo will send the user back to the home page ie the profile page.
