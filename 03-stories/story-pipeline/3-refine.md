# Stage 3: Refine

## When
Between internal groom (Tuesday week 1) and backlog groom (Thursday week 2). You have ~9 days.

## What needs to happen

This is the stage where the story goes from "discussed" to "ready for full-team review." Three tracks run in parallel:

### Design track (Amber)
- UX flows and UI assets designed for flagged stories
- Assets linked directly to the relevant AC in the story file
- Amber's weekly design review (Tuesday) is the checkpoint

**Michelle's job:** Give Amber clear AC and a specific decision to make. Not "design the detail page" but "design the detail page layout — the open question is whether competency tags go above or below the apply CTA."

### Technical track (Pow Hwee)
- API contract documented for flagged stories
- Field names, request/response shapes, error codes
- Any spikes or unknowns resolved

**Michelle's job:** Chase Pow Hwee on unresolved fields from `00-hub/open-items.md`. Make it easy — send the specific question, not "can you look at the open items list."

### PM track (Michelle)
- [ ] Update AC based on internal groom feedback
- [ ] Resolve open questions (chase owners, check `00-hub/open-items.md`)
- [ ] Identify feature flag + entry point per story
- [ ] Check: does this story touch any unconfirmed OTG fields? If yes, is the field confirmed yet?
- [ ] Check: does any AC accidentally include R1 scope? Run against MVP guardrails.

## Midpoint check (Monday week 2)

Mid-sprint review is Monday week 2. Use it to assess:
- Which stories have design ready?
- Which stories have API contract ready?
- Which stories still have open blockers?

Any story not on track for DoR by Thursday → flag it. Either descope or shift to next sprint.

## Done when
Design and API contract both attached. No open questions blocking estimation. Story is ready for backlog groom.
