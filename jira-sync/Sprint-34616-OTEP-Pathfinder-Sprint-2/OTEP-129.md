# OTEP-129: See whether an opportunity is open or closed before applying.

**Status:** Backlog
**Assignee:** N/A
**Story Points:** N/A

---

## Description

User Story As an officer, I want to know whether an opportunity is still accepting applications before I click through, so that I'm not caught off guard by a posting I can no longer act on.   Acceptance Criteria Closed or expired postings are hidden from the listing and search results - officers cannot see them in the hub.  Deep-links to closed postings show a simple posting message: “This opportunity is no longer available” with a link back to the listing.  Postings approaching their end date display a “Closing soon” label on both the card and the detail page (threshold will be 7 days or less).
